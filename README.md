# AXONYX · Defensa Inmune 3D

Juego educativo de defensa inmunitaria ambientado dentro de un vaso sanguíneo, con perspectiva tridimensional en Canvas y anticuerpos en forma de Y como proyectiles.

## Cómo jugar

Descarga `index.html` y ábrelo en un navegador. El juego es autónomo y no necesita instalar dependencias ni tener conexión a Internet.

- Pulsa **INICIAR MISIÓN** para comenzar la primera fase.
- Mueve el puntero, arrastra sobre la escena o utiliza las flechas para desplazarte.
- Mantén pulsada la barra espaciadora, la escena o el botón **Y** para lanzar anticuerpos.
- Pulsa **P**, **Esc** o el botón de pausa para detener y continuar la partida.
- Responde las preguntas de inmunología para obtener potenciadores.

## Fases

1. Patrulla vascular: neutraliza partículas virales.
2. Invasión bacteriana: enfrenta bacterias que requieren dos impactos.
3. Corriente acelerada: enfrenta variantes pequeñas y veloces.
4. Foco de infección: neutraliza al jefe final.

## Implementación y validación

HTML, CSS y JavaScript en un solo archivo. La escena usa proyección de profundidad en Canvas 2D. El botón inicial está enlazado y arranca directamente la partida.

Se verificó la sintaxis y el flujo de arranque con una simulación del entorno del navegador. La revisión visual en un navegador real sigue pendiente.

Representación educativa simplificada de la respuesta inmunitaria.
